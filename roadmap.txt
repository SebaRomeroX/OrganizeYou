ORGANIZEYOU - PROJECT ROADMAP
=============================

WHAT THE PROJECT IS
-------------------
OrganizeYou is a personal organizer/reminder web app.
First iteration focuses exclusively on a to-do list.

WHAT WE'RE DOING AND HOW
-------------------------
- Keep the tech stack as simple as possible:
  HTML, CSS and vanilla JavaScript. No frameworks, no build tools,
  no external dependencies for now.
- Single-page app runnable by opening index.html in a browser.
- Data stored in the browser (localStorage) for now; a backend may
  be considered in later iterations.
- Mobile-first design: layout and styles are written for small
  screens first, then enhanced for larger screens with min-width
  media queries.

PROJECT GUIDANCE
----------------
- Prefer simplicity over abstraction: no over-engineering.
- Plain, readable code; small files; comments only where useful.
- UI decisions follow a mobile-first approach: design for the
  smallest screen first, scale up with breakpoints.
- Touch-friendly targets (buttons/list items >= 44px), viewport
  meta tag included.
- All decisions, changes and progress are registered in this file.
- Every completed task is checked off below and noted in the log.

SECOND GOAL: CATEGORIES & TAGS
------------------------------
Decisions:
- Categories are user-created and stored in localStorage
  (organizeyou.categories). A tag is simply a reference to a
  category, so tags and categories are the same list.
- Tasks gain a tags field (array of category ids); existing tasks
  migrate to an empty array (a task with no tags is valid).
- Task list is grouped: one section per category in creation order,
  a task with multiple tags appears in each matching section, and
  untagged tasks appear under "Uncategorized" at the top.
- Tags are assigned after creation via a + button that opens an
  inline picker of category chips to toggle on/off.
- Deleting a category removes it from all tasks (no confirmation).
- No filtering by category in this goal (kept minimal).
- Categories cannot be reordered yet (creation order).
